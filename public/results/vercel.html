Vercel from mainland China.

A dedicated probe kit deploys a real Vercel site (project-silk-eta-17.vercel.app) that turns on as many products as possible, then measures it from a mainland China node across the two connection origins a real product has — the user's browser on the deployed site (frontend) and the app's server calling the Vercel API and Storage REST (backend) — plus raw host reachability (transport). Storage for this demo: Blob in Hong Kong, Redis (Upstash) in Singapore. Verdicts: Reachable, Degraded, Blocked.
